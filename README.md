# AI Cyber Security Learning Notes

A collection of notes, exercises, and project work for learning cybersecurity
and related technical skills.

## Repository contents

- `Phase0/` — foundational notes and learning resources.
- `Engineering-Notebook/` — dated learning notes and reflections.
- `Problem-Notebook/` — problem-solving notes.
- `Projects/` — project work.
- `Submissions/` — completed exercises and learning assessments.

## Working with the notes

The materials are organized by topic and learning phase. Exercises are intended
to be completed by the learner; record your own commands, outputs, observations,
and explanations in the relevant submission.
